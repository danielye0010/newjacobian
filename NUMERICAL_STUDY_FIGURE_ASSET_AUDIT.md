## 3. Geometry, clamp, field and evaluation assets — Fig. 1 / Table 1

### Locked setup

The solid is an extrusion over x in [0,40] mm of the L cross-section with polygon vertices (y,z): (-4,-4), (-4,4), (-2,4), (-2,-2), (4,-2), (4,-4). Outer width/height are 8 mm; both walls are 2 mm. The production grid has 128 axial subdivisions, 2 elements through each wall, 5,805 physical corner nodes and 3,584 C3D8I elements. The physical exterior has 4,152 quads / 8,304 STL triangles. There is no rounded CAD fillet in this mesh definition.

The entire x=0 end is clamped in all three translational DOFs. This differs from the older distributed-fixture/command-x-equality teacher model. The command and final coordinates are `X_command = round(X0 + Phi a,12)` in the execution deck and `X_final = X_command + u(a)`. Preserve nominal frame, units and node correspondence.

The G40 axial eigenstrain is `E*_xx = kappa p_weak dot ([y,z]-centroid)`, other eigenstrain components zero. Saved centroid is [-1.2857142857143198,-1.2857142857143342] mm; weak direction is [0.7071067811866069,0.7071067811864883]. N uses kappa=0.0045/mm with NLGEOM; S uses 0.0001/mm with NLGEOM; L uses 0.0045/mm without NLGEOM. Nominal material labels are fixed under compensation. Material E=70,000 MPa, nu=0.33. The adapter implements the prescribed eigenstrain through initial stress `S0=-C:E*` for the locked additive Green-strain model; do not depict it as a measured AM thermal history.

Evaluation is normalized-area, material-associated **closed finite-feature P2S**, over 16,608 surface Gauss points (49,824 vector coordinates), total nominal area 1,336 mm². It is not global nearest-neighbor P2P, an infinite-plane distance, or a registered surface comparison. The macro model has 8 faces, 18 unique edges and 12 vertices. Edge validation samples 201 points per edge, with length weighting. Vertex errors use material-corresponding macro vertices. Dimensions are overall span x=40, outer width y=8, outer height z=8, y-wall=2 and z-wall=2 mm; the code samples spans at the six cross-section corners, widths/heights at nominal x-sections, and wall thickness along specified nominal grid lines.
